# Test images

The test suite has no third-party image files.

- Every test image is generated in memory by `TestImageFactory.cs`: SkiaSharp-encoded PNG, JPEG and WebP, plus hand-built GIF, BMP, ICO, EXIF orientation segments and a header-only PNG.
- `samples/UploadApi/sample.jpg` was drawn with SkiaSharp for this repository (own work, MIT).
- `icon.png` was drawn with SkiaSharp for this repository (own work, MIT).

Any file added here must have a known license. Record its source and license in this file.
